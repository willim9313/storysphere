## ⚠️ 這是全頁視覺重做，不是局部修補

截圖是為了理解**現有功能與資料密度**，不是要延續版面。側欄＋詳情的兩欄結構、
儀表板的卡片組合、清單列的構成、空狀態構圖全部開放。**硬約束只有三條**：

1. **token 不新增、既有值不改**。`--symbol-*`（6 種意象類型）、`--polarity-*`（4 種極性）、
   `--symbol-density-*`（密度階）為本頁專屬，`--entity-*` 與知識圖譜頁共用。
   **怎麼用這些 token 完全開放。**
2. **雙主題 Warm + Ink，皆淺底**，兩套都要出。
3. **色階語意已定案**：熱圖與密度條用**跨意象**的單章最大值正規化，不可退回 per-row
   正規化（那會讓出現 13 次的意象比出現 1 次的更淡，見 brief §5 A3）。

brief §5 的痛點是**必須解決的問題，不是工作範圍的邊界**。

## 給設計側的四個重點（詳見 brief）

1. **§1 主軸轉向：從「出現幾次」換成「這個意象怎麼行為」** — 先讀這節。
   頻率在真實資料上幾乎沒有鑑別度：29 個意象裡 **17 個只出現 1 次**，最高的「海」13 次
   裡還有 5 次來自版權頁。使用者面對一份頻率排序的詞彙清單，**沒有線索決定該點哪一個**，
   所以誰都不點 —— 實測詮釋覆蓋率 `名字的潮汐` 1/29、`大唐雙龍傳` 0/23。

2. **§2 行為訊號盤點：六個零 LLM 成本的訊號** — 這是取代頻率的材料，全部可從
   `sample-payloads/` 的真實回應算出。角色依附、分布形狀、意象結盟、事件依附、
   登退場、證據可信度。**排序與清單描述都應該由這些訊號長出來。**

3. **§3.2 共現實體的三個陷阱** — 直接影響設計成立與否：
   - **自我匹配**：「海」共現次數最高的實體（12 次）就是同名的 KG 實體「海」自己。
     取 top-1 當訊號，最強的發現永遠是廢話。**必須過濾。**
   - **那些不是角色**：19 個共現實體多數是 `location` / `concept` / `object`，
     現況 UI 卻標成「共現角色」。
   - **意象與實體重疊**：「鹽」「懷錶」既是意象也是 KG 實體，兩份清單互相重複。

   過濾後「海」真正的角色依附訊號是 **伊內絲 6/13（46%）**。

4. **這頁必須在零 LLM 成本下就有用** — 覆蓋率 1/29 和 0/23 是**常態，不是例外**。
   任何把主要內容鎖在 LLM 詮釋後面的設計，都會重現 `current-05` 那個空頁。
   LLM 詮釋的定位因此改變：不是「唯一內容」，而是「把已呈現的行為訊號寫成論證」。

## 這頁的使用者是誰

**閱讀分析者，不是一般讀者。** 他要回答的是「這個意象在這本書裡承載什麼意義、
證據夠不夠」。與鄰頁的邊界：知識圖譜頁回答「誰跟誰有關係」，本頁回答
「這個意象承載什麼」—— 角色依附訊號會踩到前者的地盤，需區隔而非重做一個小型圖譜。

## 尚未定案、需要設計側一起回答的問題

見 brief §8。其中兩題最關鍵：

- **只出現 1 次的意象（29 個裡的 17 個）擺哪裡？** 在行為訊號的框架下它們幾乎沒有
  可陳述的內容 —— 收合、降級為「證據不足」、還是照常列出？
- **六個行為訊號要怎麼合成排序？** 固定啟發式，還是讓使用者切換主軸
  （「依角色依附排」／「依貫穿度排」）？

證據可信度是乘數不是加項——版權頁污染 38% 的意象，其他訊號再強也要整體降權。阻尼則處理另一種假訊號：出現 2 次、兩次都跟同一人同段＝100% 依附，那不是依附是巧合。使用者仍可切主軸（角色依附／貫穿度／事件依附／頻率／首見／審核）；分數組成在列上 hover 可見。

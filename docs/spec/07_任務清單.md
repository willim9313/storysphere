# 07 任務清單

把 00 的開工順序拆成 28 張任務，給實作的 agent 逐張領。每張的「完成標準」都要在提交時逐條回報；另外照 `CLAUDE.md` 的閘門與規格同步。

規則：

- 依編號做；同一階段內沒有依賴的可以並行。
- 一張任務若超過 3 個檔案，依 `CLAUDE.md` 先拆子步驟再做，但仍以這張的完成標準驗收。
- 標 **人工檢查** 的任務，做完要停下來等使用者看過才往下。
- 驗證文本：benchmark 的 `texts_zh/01_推理_四簽名_柯南道爾_1890_繁中譯.txt`，下文簡稱「四簽名」。
